# optics-doc-figures

Figures for two explanatory documents on optical inspection simulation.

- `solver-*.png`: how a Fourier-series scattering solver turns a layer stack into an image, shown on a small worked case (one line per 540 nm period, 436 nm light, three harmonics).
- `limits-*.png`: what limits optical detection of a small defect. `limits-5-two-modes.png` is an illustration with made-up numbers, not measured data.

All figures were computed for these documents from a toy model. None is tool or product data.
